# Static Code Analysis — Identified Issues

| Issue                                                              | Type              | Line(s)       | Description                                                                                                               | Fix Approach                                                                                                           |
| ------------------------------------------------------------------ | ----------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Weak cryptographic hash (`B324`)                                   | Security (High)   | 50            | `hashlib.md5()` is broken and insecure for hashing sensitive passenger IDs.                                               | Replace `hashlib.md5()` with `hashlib.sha256()`.                                                                       |
| OS Command Injection (`B605` / `B607`)                             | Security (High)   | 61            | `os.system("echo ... " + filename)` invokes a system shell and is vulnerable to command injection.                        | Replace `os.system()` with standard Python `print()` (or `subprocess.run` without shell).                              |
| Arbitrary code execution via `eval()` (`B307` / `W0123`)           | Security (Medium) | 45            | `eval(surcharge_expr)` executes arbitrary Python strings, creating a severe code injection vulnerability.                 | Replace `eval()` with a numeric `surcharge_rate` parameter (`base_fare * surcharge_rate`).                             |
| Hardcoded secret token (`B105`)                                    | Security (Low)    | 73            | `airline_api_secret` stores a hardcoded secret token directly in source code.                                             | Load the secret dynamically from environment variables using `os.environ.get("AIRLINE_API_SECRET", "")`.               |
| Insecure PRNG (`B311`)                                             | Security (Low)    | 54            | `random.randint(1000, 9999)` uses a predictable pseudo-random generator for security PINs.                                | Use `secrets.SystemRandom().randint(1000, 9999)` from Python's `secrets` module.                                       |
| Mutable default argument (`W0102`)                                 | Bug / Quality     | 15            | `baggage_tags=[]` is shared across all calls to `bookFlightSeat()`, leaking state between bookings.                       | Change default to `baggage_tags=None` and initialize `if baggage_tags is None: baggage_tags = []` inside the function. |
| Bare `except:` clause (`W0702` / `E722`)                           | Bug / Quality     | 30-31         | `except: pass` catches all exceptions (including `SystemExit` and `KeyboardInterrupt`) and hides errors silently.         | Catch specific `KeyError` (`except KeyError:`) when `flight_no` is not found.                                          |
| Resource leak / File not closed with context manager (`R1732`)     | Quality           | 58-60         | `open(filename, "w")` is called without a `with` statement and lacks explicit `encoding`.                                 | Use `with open(filename, "w", encoding="utf-8") as file:` to guarantee safe file closure.                              |
| Unused import & unused variable (`W0611`, `W0612`, `F401`, `F841`) | Quality / Style   | 4, 35, 44, 66 | `import math`, `airport_fee = 35.0`, and loop variable `f` are unused; `flights` parameter shadows outer scope (`W0621`). | Remove `import math` and `airport_fee`; use `_` for unused loop key and rename parameter to `flight_data`.             |
| Comparison to `None` & PEP 8 formatting (`C0121`, `E711`, `E501`)  | Style             | 23, 36        | Uses `== None` instead of `is None`, old `%` formatting on a line > 79 chars, and `camelCase` instead of `snake_case`.    | Use `is None`, f-strings, wrap lines under 79 chars, and rename functions to `snake_case` with docstrings.             |
